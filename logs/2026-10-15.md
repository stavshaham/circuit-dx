## Surprises and problems

- **First script run gave a cutoff of 10.0 Hz.** The gain never reached 0.707, so `argmin` returned the first point. Three bugs:
  1. parentheses in H closed after `R1*C1`, so `R1*C2 + R2*C2` were not multiplied by `s`
  2. `10e1` (= 100) used instead of `1e3` (= 1000) for the protection resistor
  3. capacitors entered as 10 nF (`10e-9`) instead of 100 nF (`100e-9`)
- **Second run gave 34.3 Hz:** R1 was `10e3 + 10e3` (20 kΩ) instead of `10e3 + 1e3` (11 kΩ)
- Lesson: the known cutoff value and the monotonic-gain check caught every error — keep these self-tests
- **Pico 2 W:** Arduino IDE upload failed with "No drive to deploy" (the RP2350 drive does not mount reliably on macOS during auto-reset) → workaround: BOOTSEL + drag the exported `.uf2` file. Copying via Finder is slow; `cp -X` from Terminal is faster
- **Sketch saved one folder too deep** (`firmware/blink_serial/blink_serial/blink_serial.ino`) → moved up one level
- Staged everything with `git add .` by mistake → unstaged with `git restore --staged .` and committed in separate groups
- Yesterday's log was named in DD-MM-YYYY format → renamed to `logs/2026-10-14.md` with `git mv` so logs sort chronologically
