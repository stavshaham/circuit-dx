## Research questions (in my own words)

- **RQ1:** How accurate is a simulation-trained model on physical measurements from real devices?
- **RQ2:** How do ADC resolution and noise affect accuracy, and which fault types become hard to detect first?
- **RQ3:** Can a model trained on one board be used on a different board?
- **RQ4:** Can the board run the model by itself, without a computer? Which models fit, and how fast are they?

## Surprises and problems

- **Git:** issues setting up the repository → resolved using the Git documentation
- **Python:** ran `pip install` outside the virtual environment, so packages went to the system Python → reinstalled inside `.venv`, regenerated `requirements.txt`, and updated Python and pip
- **Pico 2 W:** "Arduino Mbed OS RP2040 Boards" was the only Pico package in the default list, but it does not support the RP2350 → added the Earle Philhower core via its Boards Manager URL

## Decisions

- **Arduino IDE** instead of PlatformIO for all firmware; `firmware/` is the sketchbook, so all sketches share one Goertzel library
- **Earle Philhower core** for the Pico 2 W
- **Circuit 1 uses the original values:** 10 kΩ resistors + 100 nF ceramic capacitors (10× "104" available); electrolytic capacitors kept as backup only
- **KiCad** for schematics and single simulation checks; **ngspice called from Python** for batch simulations
- **One Python environment at the repository root**, shared by `sim/` and `ml/`
- **Log filenames use YYYY-MM-DD** so they sort chronologically
